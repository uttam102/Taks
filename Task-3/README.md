### ⛅ Task 3: Real-Time Weather App

A dynamic Python script that queries a global weather API to fetch real-time weather information for any city in the world.

#### ✨ Features
- Fetches real-time temperature, humidity levels, and weather descriptions.
- Supports any valid city globally.
- Clean JSON parsing and formatted console output.

#### 🔑 Configuration
Before running the app, you need a free API key from [OpenWeatherMap](https://openweathermap.org/api).
1. Get the key and open `weather_app.py`.
2. Replace the `YOUR_API_KEY_HERE` text with your actual API key.

#### 🚀 How to Run
First, ensure you have the `requests` library installed:
```bash
pip install requests
```
Then run the script:
```bash
python weather_app.py
```

#### 🧠 Concepts Learned
- Making HTTP GET Requests using the `requests` library.
- Accessing web APIs and API authentication.
- Working with JSON response data and handling possible network errors.
