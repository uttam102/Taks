### 📝 Task 2: To-Do List App

A Command-Line Interface (CLI) application to manage your everyday tasks efficiently.

#### ✨ Features
- **Add Tasks**: Easily enter new tasks to do.
- **View Tasks**: Display all current tasks with their status.
- **Mark as Complete**: Toggle the status of a task when you finish it.
- **Delete Tasks**: Remove items that are no longer needed.

#### 🚀 How to Run
Simply execute the Python script in your terminal:
```bash
python todo_list.py
```

#### 🧠 Concepts Learned
- Command Line Interface creation.
- Managing states using Python Data Structures (Lists & Dictionaries).
- Exception handling and validating continuous user inputs (While loops).
