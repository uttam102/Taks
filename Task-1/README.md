### 🔐 Task 1: Password Generator

A simple yet highly effective Python script that generates strong, randomized passwords.

#### ✨ Features
- Generates passwords with a mix of uppercase letters, lowercase letters, numbers, and symbols.
- Fully customizable length (minimum 4 characters to accommodate all character types).
- Simple to use interface inside the console.

#### 🚀 How to Run
Ensure you have Python installed, then run the script from the terminal:
```bash
python password_generator.py
```

#### 🧠 Concepts Learned
- String manipulation and concatenation.
- The Python `random` module (`random.choice()`).
- Program loops and input validation.
